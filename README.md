# IPA Studio 

Личный веб-каталог и инструмент для установки iOS приложений (IPA).

## ✨ Возможности

1. **Онлайн-каталог (GitHub Pages)**
   - Apple Liquid Glassmorphism интерфейс с поддержкой темной и светлой тем.
   - Фильтрация по аккаунтам Apple ID (`sinakayev@icloud.com`, `f.sinakaev@ya.ru` и др.).
   - Сортировка: по названию (А-Я, Я-А), по Apple ID, по размеру файла, по версии.
   - Быстрый поиск по названию, Bundle ID или учетной записи.
   - Установка через Safari в один клик (OTA по протоколу `itms-services`).

2. **Автоматическая генерация карточек (`generate.py`)**
   - GitHub Actions автоматически анализирует загруженные в Releases `.ipa` архивы.
   - Извлекает реальные названия приложений (даже при скрытых названиях в Bundle).
   - Вытаскивает нативные иконки прямо из IPA и декодирует проприетарный формат Apple CgBI в чистый стандартный PNG.
   - Формирует манифесты установки (`manifests/<bundleId>.plist`) и единый `apps.json`.

3. **Device Studio (Локальная и удаленная установка)**
   - Прямая установка IPА на подключенный iPhone/iPad по USB кабелю или Wi-Fi через `ideviceinstaller` (без Safari и без ограничений).
   - Поиск и загрузка приложений напрямую из App Store через встроенный движок `ipatool`.
   - Установка любых локальных `.ipa` файлов перетаскиванием (drag-and-drop).

---

## 🚀 Запуск Device Studio

Для использования прямой установки через USB/Wi-Fi запустите локальный сервер:

```bash
./start.sh
```
или:
```bash
python3 server.py
```

Сервер поднимется на `http://localhost:5050` и автоматически свяжется с веб-интерфейсом.

---

## 🛠 Автообновление каталога

Каталог автоматически обновляется в GitHub Actions при добавлении нового релиза или вручную:

```bash
python3 generate.py
```
