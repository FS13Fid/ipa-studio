Для прямой установки через USB провод на ваш iPhone устройство должно быть подключено к компьютеру с запущенным локальным сервером.

cd ipa-studio && ./start.sh

Прямо сейчас вы также можете установить это приложение без компьютера прямо с вашего iPhone в один клик через кнопку «📲 Установить (OTA)» в Safari!
